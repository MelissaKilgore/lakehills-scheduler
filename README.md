# Lakehills shared scheduler

Live board file: `board.json` in this repo.

## One-time setup (admin)

1. GitHub → Settings → Developer settings → Personal access tokens.
2. Create a token with access to this repo only (Contents: Read and write).
3. Open the scheduler HTML on each Chromebook.
4. Paste the token in **Facility edit key** → Store key on this device.
5. Optional: repo Settings → Pages → main / root so staff can use
   https://melissakilgore.github.io/lakehills-scheduler/

Treat the token like a building key. Only people who may edit the schedule should have it.

## Daily use

1. Type your name.
2. Change Front/Back assignments.
3. Tap **Save for everyone**.
4. Other Chromebooks pick up the change within about 8 seconds (or tap Refresh now).
